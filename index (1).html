    How to run any script in Linux

    1. Click Copy for terminal on the script box.
    2. Open the Linux terminal, paste it (Ctrl+Shift+V, or right-click in PuTTY) and press Enter.
    3. The file is created and runs at once. Type your inputs when the script asks.

    To make the file by hand instead: vi name.sh, press i, paste, press Esc, type :wq and Enter. Then run bash name.sh. Use bash (not sh) because these scripts use bash features like arrays and for ((...)).
